# Tipografía y restauración de Equipo

Se utilizan dos familias de texto:

- Georgia (`--font-display`) para títulos principales y encabezados editoriales.
- Montserrat (`--font-body`) para párrafos, navegación, formularios, botones y títulos secundarios.

Georgia es una fuente de sistema. Montserrat se solicita una sola vez a Google Fonts con pesos 400, 500, 600 y 700. Se mantienen fuentes de reserva para sistemas que no dispongan de ellas y las fuentes de iconos conservan sus declaraciones independientes.

Equipo recupera las plantillas de lista y perfil del commit `ea29e57`. Contacto, Entrevistas, Misión y Proyectos conservan su distribución editorial. La portada conserva contenido, imágenes y distribución; solo recibe la tipografía global normalizada.
